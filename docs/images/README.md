# README image assets

- `hero.svg` is an editable vector banner using NotchFree's existing mint palette and app-icon motif. It is branding, not a UI screenshot.
- `app-icon.png` is a PNG conversion of `Resources/AppIcon.icns`.
- The JPG files are unretouched captures of the installed NotchFree release app on 6 September 2026. The installed executable UUID matched the local release build: `AC790F11-C94C-3B3F-B073-F75869D05E31`.
- Notes and Tasks show temporary sample text, removed after capture. Calendar was not connected, Mirror was inactive, and no Shortcuts were run. The tray capture shows its empty state.
- Captures use the existing White accent and 720 pt panel width. The Appearance window was enlarged for capture, then restored.
- Music metadata and artwork belong to their respective owners and appear as displayed by the app. Shortcut names retain their original language. These captures do not establish additional hardware or provider validation; see [Validation](../VALIDATION.md).
