# NotchFree

Бесплатное приложение для macOS с открытым исходным кодом: музыка, файлы и небольшие виджеты рядом с вырезом MacBook. На экране без выреза появляется компактная панель по центру сверху.

**Это альфа-версия.** Приложение собирается на вашем Mac. Платный аккаунт Apple Developer и Developer ID не нужны. Готовый нотарифицированный установщик не распространяется.

## Установка

Нужны macOS 14.6 или новее и инструменты Apple со Swift 6.0+. Основная проверенная платформа — Apple Silicon; Intel ещё требует проверки.

1. Откройте Терминал и выполните:

   ```sh
   xcode-select --install
   ```

   Завершите установку. Если инструменты уже установлены, проверьте `swift --version`: нужна версия 6.0 или новее.

2. На странице репозитория нажмите **Code → Download ZIP** и распакуйте архив.
3. В Терминале напишите `cd ` с пробелом, перетащите распакованную папку в окно Терминала и нажмите Enter.
4. Выполните:

   ```sh
   ./scripts/install.sh
   ```

Скрипт соберёт приложение, подпишет его локальной ad-hoc подписью, установит в `~/Applications/NotchFree.app` и откроет. Первая сборка может занять несколько минут. `sudo` не нужен, настройки Gatekeeper не меняются. Локальная подпись не является нотарификацией Apple.

## Как пользоваться

- Наведите указатель на верхний центр экрана. В **Home** находятся виджеты, в **Tray** — файлы.
- Музыка берётся из системного Now Playing. В настройках можно выбрать прямое подключение к Music или Spotify.
- Прямые режимы Music и Spotify показывают обложку в плеере и рядом с вырезом. Если обложка недоступна, остаётся значок ноты.
- В Settings → Appearance → Accent color доступны шесть готовых цветов. Выбор применяется сразу и сохраняется после перезапуска. Панель стала ниже за счёт отступов; ширина по умолчанию осталась 720 pt.
- Перетащите файл на панель: в Tray сохранится отдельная копия. Command-click выбирает несколько файлов. Option при входящем переносе означает перемещение, если исходное приложение его поддерживает.
- Заметки, задачи, таймер и копии файлов сохраняются локально между запусками.
- Календарь, камера, Bluetooth и перехват клавиш громкости/яркости включаются отдельно. macOS запросит нужные разрешения.
- Настройки и выход доступны через значок приложения в строке меню.

Для обновления скачайте новые исходники и снова запустите установочный скрипт. Пользовательские данные сохранятся. После пересборки macOS иногда требует повторно разрешить доступ для установленной копии приложения.

Для удаления выключите автозапуск, завершите приложение и переместите `~/Applications/NotchFree.app` в Корзину. Данные находятся в `~/Library/Application Support/NotchFree`; проверяйте содержимое перед удалением, особенно файлы, которые вы переместили в Tray.
